# GhostCorp capability expansion catalogue

**Catalogue size: 1,200 planned capabilities (30 departments × 40 capability operations).**
**Status: PLANNED catalogue only.** A catalogue entry is not an implemented feature. Each item needs code, permissions, tests, audit events, documentation and a verified deployment before its status can change.

## Capability lifecycle

- `PLANNED`: defined in this catalogue only.
- `DESIGNED`: contracts, permissions and acceptance criteria reviewed.
- `IMPLEMENTED`: code exists in the repository.
- `TESTED`: automated and relevant integration tests pass.
- `DEPLOYED`: running in a named environment.
- `LIVE`: verified operating with real traffic or real work.

All capabilities inherit least-privilege permissions, $0 default paid-spend policy, privacy boundaries, idempotency where applicable, observability, owner kill switch and auditability.
